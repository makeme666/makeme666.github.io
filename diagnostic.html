💡 常见问题解决

  • manifest.json 404: 确保 posts/manifest.json 存在且被 GitHub Pages 正确服务（需要 .nojekyll 文件）
  • .md 文件 404: 确保 posts/*.md 文件存在，GitHub Pages 默认会服务 .md 文件
  • 自定义域名问题: 检查 Cloudflare DNS 设置，确保 CNAME 记录正确且未启用 Proxy（尝试 DNS Only）
  • 跨域问题: GitHub Pages 不支持自定义域名下的 CORS，如有问题请使用默认域名测试
