# ComfyUI基础

##  **背景**
ComfyUI 生成式AI，深度学习的用户界面框架。提供灵活高效的方式构建复杂的任务比如文生图文生视频等应用。

##  **基本原理**
ComfyUI运行逻辑：插件运行在python虚拟环境上调用模型。本质上是一个运行在本地的可视化计算图执行引擎。
1. 节点系统
2. 工作流执行
3. 模型和数据处理
4. 异步队列系统
##  **优势**
1. 模块化可定制
2. 本地运行保护数据隐私
3. 广泛模型支持，各种节点模型
##  **劣势**
1，技术要求高，会用命令行，熟悉j脚本语言python
2，硬件依赖高，内存显存足够大，推荐英伟达显卡
##  **学习网站**
国外GitHub，CIVITAI，YouTube，OpenArt，Huggingface，JC
国内LiblibAI,NoveAI,Promlib

##  **本地安装**
windows便携包或者整合包安装mac/linux建议源码安装
本地MACmini部署手动安装,具体步骤
1，安装Git
2，安装好python3.10或者3.11/12不推荐最新的
3，指定安装路径，新建Comgyui,venv文件夹
使用 Conda 创建一个环境。
```
cd /Users/ComfyUI/
conda create -n comfyenv
conda activate comfyenv
```
克隆代码仓库
```
git clone https://github.com/Comfy-Org/ComfyUI.git
```
安装GPU依赖 
```
conda install pytorch-nightly::pytorch torchvision torchaudio -c pytorch-nightly
```
安装 ComfyUI 依赖

```
cd ComfyUI
pip install -r requirements.txt
```
启动
```
python main.py
```
参考官方文档 https://docs.comfy.org/zh

## 节点KSampler采样器

| 参数名称        | 说明          | ​推荐值范围                                       | 作用效果                                             |
| ----------- | ----------- | -------------------------------------------- | ------------------------------------------------ |
| 随机种(Seed)   | 控制生成随机性的种子值 | -                                            | 用于初始化随机数生成，可保证多次运行的可复现性，本质上是潜在空间中初始噪点图的随机改变      |
| 运行后操作       | 随机种子是否固定    | 固定/随机                                        | 固定保持种子不变，随机让每次生图种子不同                             |
| 步数(Steps)   | 采样迭代次数      | 5-15（快速草图）20-30（卡通）25-40（写实）                 | 值越高细节越好但耗时增加，过低会导致图像不完整                          |
| CFG         | 提示词引导强度     | 3-6（创意发散）7-9（平衡）＞10（易畸变）                     | 值越大越“听话”，创造性越弱，值过大会过度锐化                          |
| 采样器         | 使用的扩散采样算法   | dpmpp\_2m（全能）euler/euler a（快速）dpmpp\_sde（写实） | 决定去噪算法路径，影响速度与风格,euler速度快但可能细节不足，dpmpp系列质量更高但更耗时 |
| 调度器         | 控制噪声调度策略    | karras（增强细节）normal（平滑）exponential（收敛快）       | 控制每一步去噪的幅度与节奏                                    |
| 降噪(Denoise) | 控制每步去噪的程度   | 1.0（默认完整降噪）0.5-0.8（图生图融合）＜0.3（抽象效果）          | 去噪强度，1.0 表示完全去噪，<1.0 时保留部分原始结构                   |

### 常用采样器（Sampler）

| 采样器名称             | 核心特点                                                    | 优缺点                                 | 推荐场景示例                                |
| ------------------------ | ------------------------------------------------------------- | ---------------------------------------- | --------------------------------------------- |
| Euler                  | 经典一阶欧拉去噪，计算量小                                  | ✅ 速度快                              | • 快速草图预览• 概念图、构图测试         |
| Euler a (Ancestral)    | 在 Euler 基础上加随机项，风格多变                           | ✅ 随机性强❌ 可能出现噪点            | • 艺术化尝试• 想要更多“惊喜”效果的创作 |
| LMS (Linear Multistep) | 多步线性预测，去噪平稳                                      | ✅ 稳定性好❌ 细节不如高阶方法        | • 批量渲染• 中等质量插画、漫画背景       |
| Heun                   | 二阶欧拉改进，平滑度更高                                    | ✅ 细节柔和❌ 略慢于 Euler            | • 人物肖像• 梦幻光影场景                 |
| DPM++ SDE              | Karras 提出的 SDE 算法，强调细节与噪声控制                  | ✅ 细节丰富❌ 运算最慢                | • 最终定稿（高质量人像、CG 渲染）          |
| DPM++ 2M               | 二阶动量优化 + Karras 调度                                  | ✅ 速度／质量平衡✅ 比 DPM++ SDE 略快 | • 游戏素材• 商业广告图                   |
| dpmpp\_3m\_sde         | 三阶动量优化                                                | ✅ 细节丰富❌ 随机性高                | • 高细节需求场景                           |
| uni\_pc                | 极速收敛,基于“预测-校正”机制算法现代，适配karras和normal | ✅ 速度快❌ 细节较普通                | • 5-10步出高质量图• cfg值4-7             |## 模型

### 调度器（Scheduler）

| 调度器名称        | 分配曲线（σ / timestep）                  | 效果概述                                 | 推荐场景示例                                      |
| ------------------- | -------------------------------------------- | ------------------------------------------ | --------------------------------------------------- |
| normal (正常)     | 线性均匀                                   | 稳定中庸，易调参                         | • 通用预览• 初学测试                           |
| karras            | Karras 非线性（前期去噪慢 + 后期强化细节） | 后期细节爆发，整体更精致                 | • 高质量人像• 质感丰富的 CG 场景               |
| exponential       | 指数衰减（前快后慢）                       | 前期迅速成型，后期微调                   | • 快速概念成型后留微调空间• 科技感或未来感场景 |
| sgm\_uniform      | SGM 论文线性                               | 与 normal 类似，但在论文模型对齐上更精确 | • 学术实验• 论文复现                           |
| simple            | 轻量化近线性                               | 与 normal 效果相近，但计算更省资源       | • 资源受限时批量预览                             |
| ddim\_uniform     | 针对 DDIM 的均匀分配                       | 与 DDIM 算法协同，低步数失真少           | • steps ≤ 20 加速预览• 低资源快速原型         |
| beta              | Beta 分布（中段爆发）                      | 中期细节集中，前后留白明显               | • 局部爆发式艺术效果• 强调“焦点”区域的插画   |
| linear\_quadratic | 线性 + 二次混合（前线性后二次曲线）        | 兼顾平稳+聚焦                            | • 光影渐变场景• 风景插画                       |
| kl\_optimal       | 最小化 KL 散度自动优化                     | 理论最优，但对模型和步数敏感             | • 深度研究• 对比基准测试                       |

## 文生图

文生图逻辑：
clip文本编码：将输入的文本转化成特征向量
vae图像编码：将大模型的训练集转化成特征向量【转化框架是ViT或者是ResNet】
K采样器：seed随机种子，步数，CFG，采样器，调度器，降噪
	文生图逻辑：(clip)文本模型将提示词(promt)转化成特征向量(Text Embeddings)，高斯噪声(Gaussian Noise)由种子(seed)确定后放到潜空间latents画布里，两个发送到发送到K采样器(KSample)的U-Net结合，调度器控制降噪方法，采样器控制降噪程度,经过设置的迭代步数(step)不断降噪(Denoise)生成潜空间图像（Conditioned Latents），潜空间图像再由图像编码(VAE)解码输出像素空间图像(Out image).
文生图原理参考
[https://diup4xqgsfu.feishu.cn/docx/EUHWdpHJHo9eymxOOj3cGGhyn8d](https://diup4xqgsfu.feishu.cn/docx/EUHWdpHJHo9eymxOOj3cGGhyn8d)
条件空间处理（选模型，文本编码）
潜空间迭代去噪（KSample采样器，空Latent）
像素空间转换（Vae解码）

常见模板建议按下面几部分组织 Prompt（可自由增删）
1. 修饰词/质量提升（Modifiers）：如 “masterpiece”, “highly detailed”, “8k resolution”, “cinematic lighting”。一般开头或结尾放，适当用对质量有一定提升，但滥用导致其它提示词影响变弱
2. 主体（Subject）：例如 “1girl”, “portrait of a warrior”,“long flowing hair”, “armor details”
3. 环境/背景（Environment/Background）：如 “forest at sunset”, “futuristic cityscape”
4. 光影构图:例如:front view, medium view,cinematic_lighting,Tyndall effect
5. 风格（Style）：如 “digital painting”, “oil painting style”, “photorealistic”
示例完整正向 Prompt：
(masterpiece:1.1), highly detailed, (1girl:1.2), long flowing hair, scenic forest at sunset, digital painting, cinematic lighting
示例负向 Prompt：
lowres, bad anatomy, blurry, deformed, watermark, text

原理参考带噪的潜变量（载入图片）。而非纯随机噪点，基于条件逐步去噪生图。
VAE编码器将输入的图像转换成潜空间图像发动到k采样器添加噪声，U-net根据提示词要求不断降噪生成像素空间图片。降噪值影响大，一般0.2-0.5
